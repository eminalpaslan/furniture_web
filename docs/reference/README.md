# Referans ekran görüntüleri

Bu klasöre referans sitenin (mondihome.com.tr) ekran görüntülerini koyabilirsin. Claude, ilgili ön yüz
görevlerine başlamadan önce buradaki görselleri açıp inceler (`docs/REFERENCE.md §0`).

Önerilen dosya adları:

| Dosya | İçerik |
|---|---|
| `ana-sayfa-masaustu.png` | Ana sayfa, masaüstü, tam sayfa (tarayıcıda "tam sayfa ekran görüntüsü") |
| `ana-sayfa-mobil.png` | Ana sayfa, telefon genişliği |
| `mega-menu.png` | Bir kategoriye gelince açılan menü |
| `urun-masaustu.png` | Ürün (takım) sayfası, masaüstü, tam sayfa |
| `urun-mobil.png` | Ürün sayfası, telefon genişliği |
| `urun-takim-icerigi.png` | Alttaki takım parçaları kutucuklarının yakın görüntüsü |
| `notlar.md` | (İsteğe bağlı) "şunu beğendim / şunu istemiyorum" notların |

Tam sayfa ekran görüntüsü almak için Chrome'da: `F12` → `Ctrl+Shift+P` → "Capture full size screenshot".

> Görseller yalnızca **yapı ve etkileşim** örneği olarak kullanılır; logo, fotoğraf ve metinler projeye kopyalanmaz.
